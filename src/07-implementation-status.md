# Implementation Status

> *Stub — to be written in v0.1.*

This chapter will document the verified state of every protocol
component as of the document's current revision:

- What is implemented and shipped (production-quality, in TestFlight).
- What is implemented but not yet stable (e.g. MLS group chat —
  in code, not yet documented at protocol-spec level).
- What is in active development (e.g. veil-front, Android client
  Phase 1).
- What is designed but not implemented (e.g. federation, P2P
  delivery, ML-DSA-65 post-quantum signatures, sealed sender).
- Known open security issues with severity and target-fix milestones,
  rather than self-graded "scores".

It will also list, for each platform binding, the FFI surface, the
build target, and the build instructions needed to reproduce the
reference binary.
